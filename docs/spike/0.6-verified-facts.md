**Informs:** all decisions.

## How to use this doc

Each row is a fact the design depends on. Fill in **Value** from official docs, or from a
measurement in another spike. Every row needs a **source** (a URL, or a spike experiment id like
`0.3/E10`) and a **checked** date. If a fact is false or worse than assumed, mark it ⚠ and note
which decision it affects.

Numbers you remember are not facts until they're checked. Cloudflare limits change often.
